## 職務要約

インフラエンジニアとして約8年間、データセンター運用・保守からWindows基盤更改、金融機関向けAWS基盤構築、保険基盤のAWS移行、AWSセキュリティ是正まで幅広く経験してきました。

これまで一貫して、AWSを中心としたインフラ設計・構築・運用に加え、標準化、自動化、運用改善を通じてシステムの信頼性や保守性を高めることに取り組んできました。  
AnsibleやJenkinsを活用した構築・デプロイの自動化、Task DefinitionやJenkinsパイプラインの共通化、手順書・チェックシートの整備、ナレッジ共有など、継続的な改善を推進することを得意としています。

直近では、保険基盤のAWS移行プロジェクトにおいて、コンテナ実行基盤の設計・構築やCI/CD改善を担当し、4環境の標準化やデプロイ時間の短縮を実現しました。  
現在は大手損保向けAWSセキュリティ是正プロジェクトに参画し、顧客との方針調整から是正内容の検討、実装まで一貫して担当しています。

今後は、一つのサービスやプロダクトへ継続的に関わりながら、SRE・クラウドインフラ領域において、可用性・セキュリティ・運用効率の継続的な改善を通じて、サービス品質の向上と事業の成長に貢献していきたいと考えています。

## 自己 PR

**技術的な課題解決力と組織的な改善推進力の両立**

異業種経験 (自動車製造業 11 年) を活かした独自の視点で、技術的な課題を組織的な改善に結びつけることが私の強みです。  
金融・保険業界での高セキュリティ要件対応や大規模移行において、単に技術的な解決策を提供するだけではありません。標準化・自動化によるプロセス改善を推進し、チーム全体の生産性向上につなげてきました。

**段階的改善による持続可能な価値創出**

急激な変化ではなく、段階的な改善を重視するアプローチで、短期間でも確実な成果を創出します。  
3 ヶ月の短期プロジェクトでも、後続メンバーの作業効率向上につながる改善を実施し、組織への持続的な価値提供を実現。技術的な保守作業と並行して、ドキュメント整備や作業プロセスの標準化により、プロジェクト全体の品質向上に貢献します。

**ステークホルダー連携による根本的な課題解決**

客先との密な連携により、表面的な技術課題の背後にある根本的な組織課題を特定し、包括的な解決策を提案します。  
データセンター運用では客先との協議により業務負荷の適正化を実現し、銀行内ネットワークシステムでは設計図・構成図の整備により作業品質の向上を達成。技術力だけでなく、関係者との効果的なコミュニケーションにより、プロジェクトの成功に導く実績を持っています。
